# Papero

> Status: szkic pomysłu (work in progress). Do tego dokumentu wrócimy i go rozwiniemy.

## Czym jest Papero

Projekt sklepu internetowego i jednocześnie wizytówki przedsiębiorcy, który chce sprzedawać meble warsztatowe. To pełna platforma e-commerce oparta o headless CMS, z częścią sprzedażową i promocyjną.

Projekt pełni też rolę portfolio: pokazuje moje podejście do budowania rozwiązań e-commerce od początku do końca.

## Cele

- Sklep internetowy z meblami warsztatowymi (katalog, koszyk, zamówienia).
- Headless CMS, dzięki któremu właściciel samodzielnie zarządza treścią i ofertą.
- Warstwa promocyjna (wizytówka marki, treści, kampanie).
- Realny projekt dla realnego klienta, a zarazem prezentacja moich umiejętności w obszarze e-commerce.
